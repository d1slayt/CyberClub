- [github-merge.png](../evidence/github-merge.png) — настоящий снимок merge-коммита с двумя родителями. Подпись: «Рисунок 3 — Результат слияния feature/quality в main».

Это снимки реальных страниц GitHub, без дорисовки результата. Граф Network для закрытого репозитория недоступен на текущем тарифе GitHub, поэтому предоставлен снимок реального журнала `git log --all --graph`, сохранённого в файле и опубликованного на сайте. Буквы HEAD и указатели веток в этом файле отражают момент сохранения графа, а не текущую вершину main.
