# КиберКлуб

Учебный проект по дисциплине «Качество и надёжность информационных систем». Это небольшая программа для учёта игровых сеансов в компьютерном клубе.

## Что умеет программа

- Показывает 12 компьютеров и их состояние: свободен или занят.
- Запускает и завершает игровые сеансы.
- Считает стоимость по времени и выбранному тарифу.
- Позволяет менять цену тарифов «Стандарт» и «VIP».
- Сохраняет завершённые сеансы в истории.

Всё находится в одном окне с разделами «Главная», «Сеансы», «Тарифы» и «История». Данные хранятся на компьютере, сервер не нужен.

## Запуск

Нужны Windows 10, Visual Studio 2026 с компонентом «Разработка классических приложений .NET» и .NET 10 SDK.

1. Открыть файл `CyberClub.sln`.
2. Выбрать `CyberClub.App` запускаемым проектом.
3. Нажать `Ctrl+F5`.

Также можно запустить из папки проекта:

```powershell
dotnet build CyberClub.sln -c Release
dotnet run --project CyberClub.App -c Release
```

## Как пользоваться

На главной странице нужно выбрать компьютер. В разделе «Сеансы» выбрать тариф и нажать «Начать сеанс». Чтобы завершить сеанс, нужно выбрать его строку в таблице и нажать кнопку завершения. После этого запись появится в истории.

Цена вводится в рублях за час, например `120,50`. Изменение тарифа действует на новые сеансы. У уже начатого сеанса сохраняется прежняя цена.

Оплачивается каждая начатая минута. Например, при цене 100 рублей за час сеанс длительностью 61 секунда стоит 3,33 рубля. Итог округляется до копеек.

## Структура проекта

- `CyberClub.App` — окно WPF и обработчики кнопок.
- `CyberClub.Core` — модели, работа с сеансами, расчёт стоимости и сохранение данных.
- `CyberClub.Tests` — проверки расчётов, ограничений и хранения.
- `tools/Metrics` — программа для расчёта метрик исходного кода.

## Проверки

```powershell
dotnet run --project CyberClub.Tests -c Release
```

Проверки запускаются как отдельная консольная программа. В результате выводятся строки `PASS` или `FAIL` и общее количество проверок. При ошибке программа возвращает код 1.

Расчёт метрик:

```powershell
dotnet run --project tools/Metrics -c Release -- .
```

## Хранение данных

Файл данных находится в `%LOCALAPPDATA%\CyberClub\club.json`. Предыдущая сохранённая версия лежит рядом в `club.json.bak`.

Если файл повреждён, программа показывает ошибку и не сохраняет изменения. Для восстановления нужно закрыть приложение, сохранить копию повреждённого файла и заменить `club.json` резервной копией.

Программа рассчитана на работу в одном экземпляре. Управление самими игровыми компьютерами и банковская оплата не реализованы.
